# Album AR

Android-приложение: оживление фото в бумажном альбоме (ARCore Augmented Images).

* **СМОТРЕТЬ** – камера; наведите на титул альбома, затем на фото – поверх играет связанное видео.
* **ГЕНЕРИРОВАТЬ** – 1) фото титула, 2) фото и видео в подпапки `photos/` и `videos/`, 3) связь фото↔видео.
* **ВЫХОД** – закрыть приложение.

Данные: `Android/data/com.example.albumar/files/Albums/<альбом>/{cover.jpg, photos/, videos/, album.json}`.

## Сборка на GitHub
Залейте проект в репозиторий → вкладка **Actions** → *Build APK* → артефакт `AlbumAR-debug-apk`.

Локально: `gradle :app:assembleDebug` (Gradle 8.9, JDK 17).

Требуется телефон с поддержкой ARCore (Google Play Services for AR).
